## Заавал: obsidian MCP хэрэгслээр бич

Файлын системийн `Write`/`Edit` биш, **`obsidian` MCP серверийн хэрэгслээр**
унш, бич. Хоёр шалтгаан:

1. Obsidian нээлттэй байхад өөрчлөлт **шууд дэлгэц дээр гарна** — хэрэглэгч
   юу болж байгааг хардаг
2. Плагин `[[холбоос]]`, tag, frontmatter-ыг зөв зохицуулна

MCP боломжгүй бол (Obsidian хаалттай) файлын системээр бич, гэхдээ
**«Obsidian хаалттай тул шууд файлаар бичлээ»** гэж хариундаа мэдэгд.

## Бичих зарчим

**Хийсэн зүйлээ бүү бич — сурсан зүйлээ бич.** «Урилга зассан» гэдэг
тэмдэглэл хэрэггүй; «CDN-ээс татсан шрифт интернэт муутай үед 3 секунд
цагаан дэлгэц үзүүлдэг тул base64-ээр суулгав» гэдэг тэмдэглэл хэрэгтэй.

- **Богино.** Нэг сургамж = 3-6 мөр. Урт бол хоёр тэмдэглэл болго
- **Шалтгааныг бич.** «Ингэж хийсэн» биш «ингэж хийсэн, учир нь ...»
- **Огноо тавь.** Frontmatter `updated:` эсвэл callout дотор
- **Холбо.** Холбогдох тэмдэглэлийг `[[...]]`-ээр заа
- **Давхардуулж болохгүй.** Аль хэдийн бичсэн зүйлийг дахин бүү бич —
  байгаа мөрийг **шинэчил**

## Хийх зүйлс.md-г шинэчлэх

Чеклистийг кодтой тулгах даалгавар авбал:
1. Байгаа зүйл бүрийг **бодитоор шалга** — таамаглаж бүү бич
2. Дууссаныг `- [x]` болго, устгаж болохгүй (түүх үлдэнэ)
3. Шинээр олдсоныг зохих зэрэглэлд нэм
4. Зэрэглэл: 🔴 итгэл алдагдуулах/буруу мэдээлэл → 🟡 эвгүй → 🔵 техникийн
5. Дүгнэлтээ callout болгож дээр нь тавь, огноотой
